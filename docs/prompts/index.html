The course scenario

The Lumo Cold Kopi launch

The situation
It is late October 2026. Lumo Kopi Co. launches Lumo Cold Kopi, its first ready-to-drink canned kopi, in Singapore on 1 December — six weeks away — and in Kuala Lumpur in January. The marketing team is small, the budget is S$60,000, and nothing has been produced yet: no research, no deck, no posts, no video.
Your role
You are the Lumo marketing team. Instead of juggling a dozen separate chats, you run the whole launch from one Claude Project in Cowork: its instructions, brand kit and working folder are set up once, and every task you start inside it already knows the brand.
The mission
By the end of the day the project holds everything the launch needs — verified market research, a dashboard, a deck and brief, a brand-voice skill, two weeks of social posts, a launch video — and scheduled tasks that keep it moving while you are away.

Lab 01 · Topic 01

Set Up the Lumo Launch Project

Scenario
Lumo Kopi Co. launches Lumo Cold Kopi in six weeks, and the marketing work will keep coming until launch day — exactly what a Claude Project is for. You create the Lumo Cold Kopi Launch project in Cowork, point it at a working folder, write its standing instructions, add the brand kit as context, and check that Claude understood all of it. Every later lab runs inside this project.
Objective
By the end of this lab you can create a Claude Project in Cowork with instructions, context, a working folder and a memory file.
You will build
The Lumo Cold Kopi Launch project, with instructions, three context files, a working folder and a project memory file. Uses: Claude desktop app (Cowork), Claude Projects

Steps and prompts — Create the launch project

This lab has three blocks. Block 1 is the project goal, pasted into the Create a project dialog. Block 2 is the standing instructions, pasted into the Instructions panel. Block 3 is your first task in the project.

  1. Download the course labs and open the Lab 01 data/brand-kit folder. Create an empty folder called Lumo Launch on your computer.

    Skim the three brand-kit files — you will check Claude's answers against them. The empty folder becomes the project's working folder.

  2. In the Claude desktop app, switch to Cowork, open Projects and start a new project.

    In Cowork a project is backed by a real folder on your computer, so its files stay yours to open.

  3. Under "What are you working on?" type Lumo Cold Kopi Launch, and paste Block 1 into "What are you trying to achieve?". Prompt below

    The goal is the standing context every task inherits, so write it as an outcome with a date and a measure.

    Lab 1 Block 1 — GOAL

    Paste this into "What are you trying to achieve?" in the Create a project dialog:

    Launch Lumo Cold Kopi in Singapore on 1 December 2026.
Produce the market research, a launch deck, a campaign brief,
two weeks of social media posts and a 15-second launch video,
within a S$60,000 budget, so that 25-34 year-olds on Instagram
and TikTok know the product exists by launch day.

    Name it Lumo Cold Kopi Launch, choose Use a folder and pick your Lumo Launch folder, then Create project.

  4. Choose Use a folder, pick your Lumo Launch folder, and click Create project.

    The project page opens with four panels: Instructions, Context, Folder and Scheduled.

  5. Open the Instructions panel and paste Block 2. Save. Prompt below

    Instructions are standing rules for every task. Short, checkable rules work better than general wishes.

    Lab 1 Block 2 — INSTRUCTIONS

    Paste this into the project's Instructions panel:

    You are the marketing team for Lumo Kopi Co.
- Prices are in Singapore dollars: S$3.90 per can, S$42.00 per
  12-pack. Always two decimals.
- Follow lumo-brand-guidelines.md for anything customer-facing.
- Never describe the product as healthy. You may say 5 g sugar.
- Never send an email or publish a post without my approval.
- Save every output to the project folder.
- Read lumo-project-memory.md before you start any task.
- Flag any figure that two sources disagree on. Do not pick one.

    Save the instructions, then add the three brand-kit files in the Context panel.

  6. Open the Context panel and add the three brand-kit files.

    Context is read, never edited — the right home for reference files you want kept exactly as they are.

  7. Start a new task in the project and send Block 3. Prompt below

    This is a setup check: if Claude cannot restate the goal or find the files, fix that now, before any real work.

    Lab 1 Block 3 — FIRST TASK

    Start a new task in the project and send:

    Before we start work, check your setup:
1. Restate the project goal in one line.
2. List the context files you can read and what each is for.
3. List the three instructions you think matter most.
4. From the product sheet, give me the price per can, the sugar
   per can and the launch date.
Then create lumo-project-memory.md in the project folder with
the heading "Project memory" and record: our primary audience
is 25-34 year-olds in Singapore, and our secondary market is
Kuala Lumpur, launching 15 January 2027.

    Compare the answer with the brand kit, then open your Lumo Launch folder and read lumo-project-memory.md.

  8. Check the answers: S$3.90 per can, 5 g sugar, launch 1 December 2026.

    Every figure must match the product sheet. A wrong figure here means a wrong context file.

  9. Open the Lumo Launch folder on your computer and read lumo-project-memory.md.

    A classic project has no memory panel, so this file plays that role: every task reads it (Block 2 says so), and you can edit it.

Check — done when

The Lumo Cold Kopi Launch project exists in Cowork, using your Lumo Launch folder, with the Block 2 instructions saved and the three brand-kit files under Context. Lab 02 · Topic 01

Run Market Research in Parallel Tasks

Scenario
Before anyone writes a post, the team needs to know the market. Four subjects need research — competitors, the customer survey, pricing and social trends — and none depends on another. So you start four tasks in the project at once, one per subject, each saving its findings to the folder. A fifth task merges the four files into one research brief, which you check against the data.
Objective
By the end of this lab you can split a multi-subject research job into parallel tasks and verify the merged brief.
You will build
Four research files and lumo-research-brief.docx merged from them, in the project folder. Uses: Claude Projects in Cowork, parallel tasks, web search
Data files
lumo-consumer-survey-2026.csv, lumo-competitors.csv, lumo-social-trends.csv
In the project
Instructions — HOW: Uses: save every output to the folder, and flag any figure two sources disagree on.
Context — WHAT: Uses: the launch brief, so every task knows the product, price and audience.
Folder — WHERE: Adds: copy in the three CSVs; four research files and lumo-research-brief.docx are saved here.
Scheduled — WHEN: Not used — you start the four tasks yourself, now.

Steps and prompts — Research the market in four parallel tasks

    Do not wait for it — start the next task straight away.

  4. Start a second task and send Block 2. Prompt below

    Several tasks can run in one project at the same time.

    Lab 2 Block 2 — CUSTOMERS

    Start a second task and send:

    Research CUSTOMERS using lumo-consumer-survey-2026.csv: the share

research-2-customers.md in the project folder.

    Start the third task.

  5. Start a third task and send Block 3. Prompt below

    Pricing reads both files; it does not need the other tasks' results.

    Lab 2 Block 3 — PRICING

    Start a third task and send:

    Research PRICING using lumo-competitors.csv and
lumo-consumer-survey-2026.csv: where S$3.90 sits against the

    Start the fourth task.

  6. Start a fourth task and send Block 4. Prompt below

    You are now the lead agent: four workers, four subjects, one goal.

    Lab 2 Block 4 — TRENDS

    Start a fourth task and send:

    Research SOCIAL TRENDS using lumo-social-trends.csv: the three

  7. When the four research files are in the folder, start a fifth task and send Block 5. Prompt below

    The merge task reads the files, not the other conversations — so the folder is how the tasks share their work.

    Lab 2 Block 5 — MERGE

    When all four files are in the folder, start a fifth task and send:

    Merge research-1-competitors.md, research-2-customers.md,

folder into one research brief, lumo-research-brief.docx:
a one-paragraph summary, one section per subject with the key
numbers, and three recommendations for the launch. Name the
source file under each section, and flag anything the four
files disagree on.

    Instagram 136 (34%), TikTok 104 (26%); Taste 124 (31%); competitor median S$4.30 with S$3.90 below it; 228 (57%) would pay S$3.50 or more.

  10. Check the trends section and the recommendations.

    The top theme should be Taste tests and first-sip reactions. Do the three recommendations follow from the numbers above them?

Check — done when

The project folder holds the four research files and lumo-research-brief.docx, whose summary, four sections and three recommendations name their source files. The brief reports 400 respondents, 248 likely to buy (62%), 112 of 152 aged 25-34 (74%), Instagram as the top discovery channel at 34%, Taste as the top driver at 31%, a competitor median of S$4.30 with Lumo's S$3.90 below it, 228 respondents (57%) willing to pay S$3.50 or more, and Taste tests and first-sip reactions as the top content theme.

Steps and prompts — Build the Market Insights dashboard

  1. In the project, send the lab prompt with the two CSV files attached or in Context. Prompt below

    The project already knows the brand colours from the guidelines in Context — you do not attach them again.

    Lab 3 Prompt
    Using lumo-consumer-survey-2026.csv and lumo-competitors.csv, build
a Live Artefact: an interactive Market Insights dashboard for the
Lumo Cold Kopi launch.

Include:
- KPI tiles: respondents, % likely to buy (intent 4 or 5), top
  discovery channel, competitor median price.
- A bar chart of discovery channels.
- A bar chart of purchase drivers.
- A price ladder: the six competitors and Lumo at S$3.90, cheapest
  to dearest, with Lumo highlighted.
- A filter for city: All, Singapore, Kuala Lumpur. The KPI tiles and
  both survey charts must follow the filter.

Bake the data into the artefact - do not fetch anything. Use the
Lumo brand colours from the brand guidelines. Title it
"Lumo Cold Kopi - Market Insights".

  2. Check the KPI tiles with the filter on All.

    400 respondents, 62% likely to buy, Instagram top channel, competitor median S$4.30 — the same numbers as the Lab 2 brief.

  3. Switch the filter to Singapore, then Kuala Lumpur.

    The respondents tile should read 240, then 160. If a chart does not change, ask Claude to wire it to the filter.

    Refining by conversation is the normal way to work — you never edit the code yourself.

  6. Save the artefact, then download a copy as HTML.

    A saved artefact persists and can be reopened; the download is a file you can share with someone who does not use Claude.

Check — done when

The Market Insights artefact shows 400 respondents, 62% likely to buy, Instagram as the top channel and a S$4.30 competitor median. The city filter changes the respondent count to 240 (Singapore) and 160 (Kuala Lumpur) and both survey charts follow it. The price ladder runs from S$3.20 to S$5.60 with Lumo highlighted at S$3.90. The artefact is saved and an HTML copy is downloaded.
